# 人生规划

**把一年的方向，落到这一周能做完的事。**

Windows 上的本地人生规划工具。没有账号，没有云，数据只在你的电脑里。

当前版本 **1.0.0**

---

## 这是什么

不是待办清单，也不是日记本。

你先给生活的几个方面打个分，立一个今年真想做成的目标，再写一件这周能做的事、一个要养成或戒掉的习惯。周末花几分钟复盘。周、月、年，一条链转起来。

## 日常怎么用

|  | 打开它 | 做什么 |
| --- | --- | --- |
| 🏠 | **首页** | 今日焦点、习惯打卡、本周在推进的目标、人生之轮 |
| 🧭 | **维度** | 固定 8 个生命之轮维度，可改名称和颜色；打 1–5 分看哪里失衡 |
| 🎯 | **目标** | 人生 / 年 / 季 / 月 / 周都可单独立，也可以往下挂 |
| ✅ | **任务** | 这周要做的事；可以不挂目标，也可以挂覆盖本周的年 / 季 / 月目标 |
| 🔁 | **习惯** | 养成或戒除。勾上表示今天成功 |
| ✍️ | **随记** | 感悟、日记、吐槽，想写再写 |
| 🪞 | **复盘** | 周结束当天看一周；月过完看上个月；年过完看上一年 |

首次打开有短引导：打分 → 年度目标 → 一件这周能做的事 → 一个习惯。随时可以跳过。

## 功能一览

### 🎯 目标

- 层级：人生、年、季、月、周。每一层都可以单独存在；有上级时再挂上去。周任务不必先有周目标。
- 独立的那一层要写「为什么重要」；挂在别人下面的可不写，展示时沿用最近的上级理由。
- 进度自己填；本周做了几件任务会另算一笔，不替你改进度。
- 人生目标是方向，不直接挂任务，一年在年复盘里看一眼就够。

### ✅ 任务

- 在任务里点星标，标成当天焦点；首页两边最多先露出 5 条，多了可以滚动。
- 没做完的可以拖到下周；周复盘提交时也能顺手带出下周任务。
- 提交或跳过复盘后，这一周的任务只读，避免事后改账。

### 🔁 习惯

- **养成**：做到就勾。
- **戒除**：守住就勾。两边都是「今天成功」。
- 可挂到同一维度的目标上；复盘里会显示完成率和所挂目标。
- 最近 7 天可以补记，再早不能改。
- 暂时不练用停用，打卡记录保留。要从详情页删除，会连打卡一起去掉；已经提交的复盘不受影响。

### 🪞 复盘

- **周**：本周最后一天才能写。任务、习惯、本周目标，再答四个问题。
- **月 / 年**：周期结束后才进待处理。满意度、习惯、上级目标上的任务证据；可选重打维度分。
- 提交后数字冻住。随记不进复盘。

### ✍️ 随记

树洞、感悟、日记都在这里。只在随记页里看，不挂到目标上，也不进复盘。不写也不耽误闭环。

### 💾 数据在你手上

- 数据库：`%APPDATA%\com.lifeplanner.app\life-planner.db`
- 每天打开会自动在本机打一份备份。
- 可导出 JSON 换电脑；可把备份同步到你指定的文件夹（OneDrive、NAS、U 盘都行）。
- 日历导出是**一次性快照**（本周任务 + 今天还没勾的习惯），不会自动跟着改。
- 每日提醒只在软件开着时，在窗口里提示今天的习惯和待办。

## 怎么开始

1. 安装 `人生规划_1.0.0_x64-setup.exe`（当前用户即可，一般不用管理员）。
2. 系统需要 WebView2，安装包会在缺少时帮你下载。
3. 打开后走一遍引导，或直接跳过，从首页开始。

> Windows 可能提示「未签名」。这是安装包没有购买代码签名证书，不是病毒。信任来源的话，选仍要运行即可。

恢复出厂会先自动备份，再用那份备份可以找回。
